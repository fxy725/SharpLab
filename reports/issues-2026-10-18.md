## 主要遗留问题（按建议处理顺序）

### 1. 编辑器自动补全会删除甚至清空代码——最高优先级

- [#1316](https://github.com/ashmind/SharpLab/issues/1316)、[#1352](https://github.com/ashmind/SharpLab/issues/1352)、[#1358](https://github.com/ashmind/SharpLab/issues/1358)：接受补全或继续输入后，光标前内容被删除，甚至整页清空；用户报告跨浏览器、跨模式出现。讨论将这三项关联起来，但尚无证据证明全部触发条件属于同一根因。
- 维护者在 #1352 于 2024-12-13 重新部署后曾暂时无法复现，并明确表示不确信根因已解决；随后的用户回复和 2025 年 #1358 的回复继续报告问题。
- 有用户称本地 main 正常，提示需要分别排查部署环境、前后端协议和编辑器状态，不能直接认定本地源码必然有相同表现。
- 2026-08-12 出现社区尝试：[GrahamTheCoder/mirrorsharp PR #1](https://github.com/GrahamTheCoder/mirrorsharp/pull/1)，题为 completion echo race。截至调查时仍 open、merged=false，而且目标是个人 fork，不是 SharpLab 主仓库。它是可研究的候选修复，不是已交付修复。

### 2. 部分在线目标持续断线、不可用

- [#1369](https://github.com/ashmind/SharpLab/issues/1369)：选择 Extensions 工作集后一直显示 connection lost；2026-07 的回复补充默认 x64 也存在问题，改用 .NET Framework (x86) 对该用户有效。
- [#1362](https://github.com/ashmind/SharpLab/issues/1362)：报告 2024 年以来的部分分支和 main 不能连接，清缓存没有解决。
- [#1359](https://github.com/ashmind/SharpLab/issues/1359)：缓存 CDN JSON 返回 404；评论报告清除浏览器应用数据后恢复，并认为与 Edgio 退役有关。这只是评论提供的绕过方案和归因，未验证为当前仍存在的全站故障。

### 3. JIT 反汇编无法完整输出或不支持常见代码

- [#1334](https://github.com/ashmind/SharpLab/issues/1334)：新 ClrMD 适配未完成；[#1368](https://github.com/ashmind/SharpLab/issues/1368) 在 2026 年仍报告 Method signature was not found / Failed to find JIT output。
- 当前 main 的 `source/Server/Decompilation/JitAsmDecompiler.cs` 仍保留失败提示并引导跟踪 #1334，可确认这不是仅从旧标题推测出来的遗留事项。
- [#197](https://github.com/ashmind/SharpLab/issues/197)、[#327](https://github.com/ashmind/SharpLab/issues/327)、[#346](https://github.com/ashmind/SharpLab/issues/346)、[#1347](https://github.com/ashmind/SharpLab/issues/1347)：静态构造函数限制会波及编译器生成的 lambda 缓存类型，即使用户没有显式编写静态构造函数。当前源码仍显式拒绝此类代码。
- [#99](https://github.com/ashmind/SharpLab/issues/99)：JitGeneric 的引用类型实参支持缺口。
- [#425](https://github.com/ashmind/SharpLab/issues/425)、[#1251](https://github.com/ashmind/SharpLab/issues/1251)：分层编译行为及提示仍有历史待办。#1251 的专家评论澄清其示例是 FullOpts，不能把该 Issue 概括成“所有输出都是未优化 Tier0”。更准确的问题是输出环境与真实运行场景的差异和解释不足。

## 维护现状

实时 API 显示仓库尚未 archived 或 disabled。main 最新提交为 d7d0ee168ef05dd30e7a3f08307f3c30bbaf8168，时间为 2024-11-18 21:54:51 UTC（北京时间 2024-11-19），主题是更新 setup.ps1 到 .NET 9。维护者在 #1316 的 2024-11-18 评论中表示已有一段时间没做 SharpLab 工作。2025 年提出的 [#1363](https://github.com/ashmind/SharpLab/issues/1363) 询问维护状态，所查评论没有维护者给出明确恢复计划。
